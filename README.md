# Git CLI Homework
- **What is the purpose of the staging area in Git?**  
  It allows me to review and group changes before committing them.

- **When would you use `git fetch` instead of `git pull`?**  
  When I want to see what changed on the remote without merging it into my code yet.

- **What are the benefits of using branches in Git?**  
  It keeps the main branch stable and allows work on features independently.

- **Why is SSH a better option than GitHub password?**  
  It’s more secure and doesn't require entering credentials every time.

- **What challenges did you face?**  
  Resolving merge conflicts and configuring SSH for the first time.
